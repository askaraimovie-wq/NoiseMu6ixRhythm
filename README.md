# Noise Mu6ix Rhythm v1.0.6 (VST3)

## v1.0.6-ல் செய்துள்ள மாற்றங்கள்:
1. **பெரிய, முழு-அகல Key Map Editor + Scrollable EDIT பேஜ்:**
   - `EDIT` பேஜ் இப்போது கீழே ஸ்க்ரோல் ஆகும் வகையில் அமைக்கப்பட்டுள்ளது.
   - Key Map Editor-ன் பக்கத்தில் இருந்த `FRR`, `FVL`, `PITCH` பட்டன்கள் மேலே கொண்டுவரப்பட்டு, Key Map Editor பெரியதாகவும் முழு அகலமாகவும் மாற்றப்பட்டுள்ளது.
   - `ROOT` பட்டன் நீக்கப்பட்டுவிட்டது — `EDIT` பேஜில் Key Map Editor பியானோவில் எந்த கீ-யை **Left-Click** செய்கிறீர்களோ அதுவே உடனே Root Key (மஞ்சள் `R`) ஆக செட் ஆகும்.
2. **Velocity Grid (EDIT பேஜில் மட்டும்):** Key Map Editor மேலே `Vel Grid` (`Free`, `2`, `4`, `8`, `16`) மற்றும் இடதுபுறம் Velocity எண்கள் (0–127) சேர்க்கப்பட்டுள்ளன.
3. **டீபால்ட் Blue கலர் + Color Selector:** புதிதாக மேப் செய்யும் எல்லா கீ-க்களும் டீபால்ட்டாக **Blue** நிறத்தில் வரும். மேலே உள்ள Color Dropdown மூலம் 12 நிறங்களில் எதை வேண்டுமானாலும் மாற்றிக்கொள்ளலாம் (`.mn6x` பிரீசெட்டிலும் சேவ் ஆகும்).
4. **MAIN பேஜ் — Full-Width Rhythm Sequencer, Typeable BPM & Extended Grid:**
   - `LOOP` பட்டன் கீழே `Grid` பக்கத்தில் கொண்டுவரப்பட்டு, Rhythm Sequencer முழு அகலமாகப் பெரிதாக்கப்பட்டுள்ளது.
   - `BPM` நாப் நீக்கப்பட்டு, நீங்களே நேரடியாக டைப் செய்யும் `BPM` பாக்ஸ் அமைக்கப்பட்டுள்ளது.
   - `Grid`-ல் **`1/4`, `1/8`, `1/12 (T)`, `1/16`, `1/24 (T)`, `1/32`, `1/48 (T)`, `1/64`** ஆகிய அனைத்தும் சேர்க்கப்பட்டுள்ளன.
