# RYTHME v1.2.5 (VST3)

## இந்த வெளியீட்டில் சரிசெய்யப்பட்டவை:
1. **Gear Icon (`⚙`) & Accurate Customize Overlay (`Default Grid: 20x`):**
   - மேல் வலது மூலையில் தெளிவான Vector Gear ஐகான்; கிளிக் செய்தவுடன் `Grid: 20x` டீபால்ட்டாக இருக்கும்.
   - `getLocalArea` மூலம் துல்லியமான Coordinate Alignment—நீலப் பெட்டிகள் இனி விலகாது!
   - `MAIN` மற்றும் `EDIT` பக்கங்களில் உள்ள **ஒவ்வொரு கண்ட்ரோல், ஃபேடர், சுவிட்ச், பட்டன், சீக்குவன்சர், டிஸ்ப்ளே** அனைத்தையும் தனித்தனியாக இழுத்து நகர்த்தவும், கீழ்-வலது மூலையில் பிடித்து அளவு மாற்றவும் (`DONE` / `Reset`) முடியும்; Preset போல சேவ் ஆகாது.
2. **Mouse Click & Scroll Protection:**
   - **Single Right-Click:** எண் டைப் செய்யும் (Type-In) பாக்ஸ் திறக்கும்.
   - **Double Left-Click:** அந்தந்தக் கண்ட்ரோலின் Default மதிப்புக்குத் திரும்பும்.
   - **No Mouse-Wheel Interference:** `EDIT` பக்கத்தில் ஸ்க்ரோல் செய்யும்போது எந்த ஃபேடரும் நம்பர் பாக்ஸும் நகராது.
3. **10 Distinct Visual Styles (`Fader Style 1..10`, `Switch Style 1..10`, `Knob/Box Style 1..10`):**
   - கலர் மட்டுமல்லாமல் உண்மையான வடிவமும் தோற்றமும் மாறும் 10 தனித்தனி ஸ்டைல்கள்.
