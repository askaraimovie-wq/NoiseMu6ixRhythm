# Noise Mu6ix Rhythm v1.0.3 (VST3)

## v1.0.3-ல் செய்துள்ள மாற்றங்கள்:
1. **FRR-ல் Panning நீக்கம்:** Fake Round Robin-ல் இருந்து Panning முழுவதுமாக நீக்கப்பட்டுவிட்டது (Kick/Snare சென்டரிலேயே பஞ்சியாக இருக்கும்).
2. **Real Round Robin (Multi-Sample per Key) & Empty Track:**
   - Key Mapper-ல் எந்த கீ-யிலும் **டபுள் கிளிக்** செய்தால் அந்தக் கீ-யில் ஒரு **Empty Track** உருவாகும்.
   - கீழே உள்ள **Sample Wave Editor**-ல் 2, 3, 4+ WAV சாம்பிள்களை Drag & Drop செய்தால், அவை அனைத்தும் அதே கீ-யில் **Track 1, Track 2, Track 3...** எனச் சேர்ந்து தானாகவே Real Round Robin-ல் இயங்கும்.
   - வேவ் எடிட்டர் மேலே உள்ள **Track Dropdown** மூலம் ஒவ்வொரு டிராக்கையும் பார்க்கலாம்; பக்கத்தில் உள்ள **`RR`** பட்டன் மூலம் Real Round Robin-ஐ ON/OFF செய்யலாம்.
   - மேலே உள்ள **`FRR`** (Fake RR) ஒரு கீ-யில் ஒரே ஒரு சாம்பிள் இருக்கும்போது மட்டும் செயல்படும்.
3. **`ALL` கீ நீக்கம் + Transport (PLAY/PAUSE, SYNC, BPM):**
   - பியானோவில் இருந்த கருப்பு `ALL` கீ நீக்கப்பட்டுவிட்டது.
   - ரிதம் சீக்குவன்சர் கீழே **`PLAY / PAUSE`**, **`SYNC`**, மற்றும் **`BPM`** நாப் சேர்க்கப்பட்டுள்ளது.
   - `LOOP` + `SYNC` ஆன் செய்துவிட்டு DAW-ல் (FL Studio) **Spacebar** அழுத்தினால், உங்களுடைய DAW BPM-உடன் சின்க் ஆகி ரிதம் தானாக ஓடும். `SYNC` ஆஃப் செய்தால் பிளக்கினின் சொந்த **`BPM`** நாப் வேகத்தில் `PLAY` / Spacebar மூலம் ஓடும்.
