# Noise Mu6ix Rhythm v1.0.2 (VST3)

## v1.0.2-ல் சேர்க்கப்பட்டுள்ள புதிய அம்சங்கள்:
1. **PITCH Toggle (Drums vs Strings):** Key Mapper பக்கத்தில் `PITCH` பட்டன் சேர்க்கப்பட்டுள்ளது (OFF = ட்ரம்ஸுக்கு பிச் மாறாது; ON = ஸ்ட்ரிங்ஸ்/மெலடிக்கு கீ-க்கு ஏற்ப பிச் மாறும்).
2. **Sample Wave Editor Panning (`Pan`):** வேவ் எடிட்டர் நாப்களில் `Pan` நாப் சேர்க்கப்பட்டுள்ளது.
3. **Compact Size + Clickable Title Resize:** பிளக்கின் சைஸ் சுருக்கப்பட்டுள்ளது (100% Default = 920x590). மேலே உள்ள **NOISE MU6IX RHYTHM** டைட்டிலை கிளிக் செய்தால் **50%, 75%, 100%, 125%** என சைஸை மாற்றலாம்.
4. **Double-Click Key Mapper:** Key Mapper-ல் எந்த கீ-க்கு நேராகவும் டபுள் கிளிக் செய்தால் ஃபைல் ஓபன் ஆகி அந்தக் கீ-யில் சாம்பிள் மேப் ஆகும்.
5. **Per-Key Rhythm Sequencer + Multi-Rhythm + Black `ALL` Key:** ஒவ்வொரு கீ ஜோனுக்கும் தனித்தனி ரிதம் பேட்டர்ன் இருக்கும். 2–3 கீ-க்களை சேர்த்து அழுத்தினால் எல்லா ரிதம்களும் ஒரே நேரத்தில் ஓடும். கீபோர்டின் இடது ஓரத்தில் உள்ள கருப்பு **`ALL`** கீ (B0) அழுத்தினால் மொத்த ரிதம் சீக்குவன்சர்களும் ஒன்றாக ரன் ஆகும்.
6. **1000+ Fake Round Robin (FRR) & Continuous Fake Velocity Layer (FVL):** ஒரே சிங்கிள் ஹிட்டில் இருந்து 1000-க்கும் மேற்பட்ட நுண்ணிய மாறுபாடுகளை (Micro-Pitch, Transient Shift, Pan, Filter, Gain) உருவாக்கும் வகையில் அப்டேட் செய்யப்பட்டுள்ளது.
