# Noise Mu6ix Rhythm v1.0.5 (VST3)

## v1.0.5-ல் செய்துள்ள மாற்றங்கள்:
1. **இரண்டே டேப் பட்டன்கள் (`MAIN` & `EDIT`):** மேலே இருந்த கூடுதல் பட்டன்கள் அனைத்தும் நீக்கப்பட்டு **`MAIN`** மற்றும் **`EDIT`** என 2 பட்டன்கள் மட்டுமே வைக்கப்பட்டுள்ளன.
2. **`MAIN` டேப்:**
   - மேலே **Key Map (View Only)** — எங்கெங்க சாம்பிள்கள் உள்ளன என்று மட்டும் பார்க்கலாம்; நகர்த்தவோ/எடிட் செய்யவோ முடியாது. பக்கத்து பட்டன்கள் (`FRR`, `FVL`, `PITCH`, `ROOT`) இங்கு இருக்காது.
   - கீழே **Rhythm Sequencer** மற்றும் அதற்கான Transport (`PLAY/PAUSE`, `SYNC`, `BPM`, `Shuffle`, `Time Rnd`, `Vel Rnd`, `Grid`) கண்ட்ரோல்கள் மட்டும் இருக்கும்.
3. **`EDIT` டேப்:**
   - மேலே **Key Map Editor** + பக்கத்தில் **`FRR`**, **`FVL`**, **`PITCH`**, **`ROOT`** பட்டன்கள்.
   - **Root Key செலக்சன்:** `ROOT` பட்டனை ஆன் செய்து பியானோ கீ-யில் **Left-Click** செய்தாலோ, அல்லது எந்த கீ-யிலும் நேரடியாக **Right-Click** செய்தாலோ அது அந்த இன்ஸ்ட்ருமென்ட்டின் Root Key (மஞ்சள் `R`) ஆக செட் ஆகும்.
   - கீழே பெரிய அளவில் **Sample Wave Editor** + Per-Zone 13 நாப்கள் + Real RR (`Track 1, 2, 3...`).
4. **Empty Preset Name Box:** மேலே பிரீசெட் பாக்ஸ் காலியாக (`---`) இருக்கும்; கிளிக் செய்து உங்களுக்கு விருப்பமான பெயரை டைப் செய்து சேவ் செய்யலாம்.
5. **VST3 ஃபைல் பெயர்:** `Noise Mu6ix Rhythm v1.0.5.vst3` என உருவாகும்.
