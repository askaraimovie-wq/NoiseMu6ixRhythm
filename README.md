# Noise Mu6ix Rhythm v1.0.7 (VST3)

## v1.0.7-ல் செய்துள்ள மாற்றங்கள்:
1. **டபுள் கிளிக் Empty Slot நீக்கம்:** Key Map Editor-ல் டபுள் கிளிக் செய்தால் காலியான ஸ்லாட் உருவாகாது — சாம்பிளை Drag & Drop செய்தால் மட்டுமே புதிய ஜோன் உருவாகும்.
2. **Right-Click மட்டுமே Root Key:** Key Map Editor பியானோவில் **Right-Click** செய்தால் மட்டுமே Root Key செட் ஆகும்; **Left-Click** செய்தால் நோட் வாசித்துப் பார்க்க மட்டுமே பயன்படும்.
3. **Multi-Select (Marquee Box-Drag + `ALL` பட்டன்):**
   - Key Map Editor-ல் காலியான இடத்தில் மவுஸை அழுத்தி இழுத்து (Box-Drag) பல வெலாசிட்டி லேயர்கள்/ஜோன்களை ஒன்றாக செலக்ட் செய்யலாம்.
   - மேலே உள்ள **`ALL`** பட்டன் (அல்லது `Ctrl+A`) மூலம் எல்லா ஜோன்களையும் ஒரே கிளிக்கில் செலக்ட் செய்யலாம்.
   - செலக்ட் செய்த பல ஜோன்களை ஒன்றாகவே இழுத்து வேறொரு கீ-க்கு நகர்த்தலாம் (வெலாசிட்டி லேயர்கள் கலையாமல் அப்படியே நகரும்).
4. **இன்னும் பெரிய Key Map Editor & Sample Wave Editor:** ஸ்க்ரோல் ஆகும் `EDIT` பேஜில் Key Map Editor (`345px`) மற்றும் Sample Wave Editor (`200px`) இரண்டும் இன்னும் பெரியதாக விரிவாக்கப்பட்டுள்ளன.
5. **Velocity Grid (64 வரை):** `Vel Grid`-ல் **`Free`, `2`, `4`, `8`, `16`, `32`, `64`** என விரிவாக்கப்பட்டுள்ளது.
